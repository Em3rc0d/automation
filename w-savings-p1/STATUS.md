## Pilot feedback rule

A real discovery can change P1 order when evidence shows a repeated pain point with:
- meaningful manual volume;
- measurable minutes per unit/batch;
- an identifiable system of record;
- acceptable connector cost;
- a bounded exception path;
- reuse potential across more than one MYPE.

Any priority change must be documented. Client urgency does not automatically equal reusable baseline priority.

## Boundary

P1 factory work must not be represented as progress on MK1 real-pilot gates. MK1 still needs a real funded/paying pilot, verified provider account/scopes, agreed SavingsBaseline, controlled live execution, tenant isolation evidence and explicit client acceptance.
